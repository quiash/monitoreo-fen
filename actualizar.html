Preparar actualización del visor

Selecciona una nueva copia portable del mapa que ya contenga los datos actualizados. El archivo se procesa en tu equipo.

Esperando el HTML actualizado.

  1. Descarga y descomprime el ZIP.
  2. Abre el repositorio y pulsa Add file → Upload files.
  3. Arrastra los archivos y carpetas del ZIP descomprimido, incluidos assets y data. Confirma con Commit changes.

La herramienta prepara la publicación; no consulta las fuentes ni cambia la fecha de los datos.
